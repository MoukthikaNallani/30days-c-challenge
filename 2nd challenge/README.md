ALGORITHM
1. Start.
2. Declare the variables distance, mileage, price, fuel and cost as float.
3. Read the distance (km), the mileage (km/litre) and the fuel price (Rs/litre).
4. Calculate the fuel required:  fuel = distance / mileage.
5. Calculate the total fuel cost:  cost = fuel * price.
6. Display the fuel required and the total fuel cost.
7. Stop.
